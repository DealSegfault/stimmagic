# Release Notes

## The Image Editor

- A rebuilt, non-destructive image editor. Every edit is a step in a stack you can reorder, hide, re-open, or delete — the picture is redrawn from the steps, so nothing is baked in until you save.
- Six tool families: Crop, Retouch, Generate, Paint, Adjust and Annotate.
- Selection is always available, so you never have to leave the tool you are working in to make one. Rectangle and ellipse marquees, freehand and magnetic lasso, magic wand with a tolerance, a mask brush, object select by click or by name, and linear and radial gradient masks you can re-drag after seeing the result. Selections combine with add, subtract and intersect.
- Generate hands part of the picture to a model: Remove object, Remove background, Regenerate a selection from a description, and Expand the canvas outward. Results arrive as candidates you choose between, and only the pixels inside your selection change.
- Retouch: heal, clone, patch, dodge, burn, sponge, blur and sharpen. Each stroke stays editable — change its strength after the fact.
- Adjust: Light, Color, Detail, Mixer, Point color, Grading, Effects and Stylize, plus a Looks strip and one-click Autos. Make a selection first and the adjustment applies only there. You can limit an existing adjustment to a selection, or release it back to the whole image, at any point.
- Annotate: arrows, freehand, rectangles, ellipses, lines, text and redaction, each its own step with its own properties.
- Crop, straighten, flip and rotate move the picture behind a pinned frame, so you see the result while you drag. Masks, paint layers and annotations travel across a crop and back without losing quality.
- Save writes a new version of the asset. Re-opening the image resumes the stack where you left it.
- The info panel's lineage says what the editor did — one line per step, newest first.
- Open editors appear in the sidebar, so several images can be in progress at once.
- Assets edited in Stimma carry an "edited" marker you can filter on.
- Projects saved by the previous editor convert the first time you open them.

## ComfyUI-Stimma

- MiniMax H3 arrives as text-to-video and image-to-video workflows, generating synchronized stereo audio together with the video. Image-to-video accepts optional first and last frames, and both workflows use faster FP8 weights with workflow-scoped SageAttention acceleration.
- RMBG 2.0 removes image backgrounds locally and returns transparent PNGs.
- Flux.2 Klein 9B gains local outpainting, while its inpainting workflow can use up to nine reference images.
- LTX-2.3 text-to-video and image-to-video can use an optional voice recording to guide the generated speaker.

## Vector & SVG

- SVG is a first-class document type. Icons, logos, wordmarks and badges can be drawn and revised in chat as versioned artifacts.
- Export gives you the source, PNG at any size or as a set, vector-preserved PDF, three embeddable code forms, and app icon bundles for macOS, Windows, iOS, Android and web. Every icon size is drawn from the vector rather than shrunk from one raster.
- The SVG viewer has a scale menu with real pixel widths from 16px up, and remembers your background choice.

## Tools

- Topaz Labs joins Stimma Account with eight image and video enhancement tools.
- Object removal, regional editing and canvas expansion arrive as cloud tools, including FLUX Erase and FLUX Outpainting.
- Inpainting is available on every Nano Banana and Flux.2 tier rather than only the top one, and the Nano Banana lineup matches Google's current models.
- Two new upscalers: P-Image and Bria.
- Four new built-in image tools that run on your own machine: Film Stock, Develop, Color Grade, and Lens & Optics, which carries 102 real lens profiles. All four are built on Jérémie Louvaert's ComfyUI-Darkroom, adapted with thanks and used under the MIT license.
- Claude Opus 5 and Kimi K3 replace their predecessors in the chat model catalog.

## Inpainting on the Tool Screen

- Rebuilt mask editor. Paint tools stay in the toolbar, while contract, expand, invert and clear move to a strip under the canvas, so a narrow column never clips them.
- New prep controls for the source image: flip, rotate, crop, scale and extend canvas. Your mask transforms along with the image. Area added by extending starts out masked, so extend, then generate, outpaints.
- The tool assistant can work the mask for you: mask or unmask a subject by name, expand, contract, invert, or clear.
- Inpaint tools take reference images of their own, so you can point at the look or the subject you want painted in.
- Outpaint controls read the same way everywhere: four edges, each a percentage of the source.

## Models & Reasoning

- Model choice splits into four per-profile roles — Quick Tasks, Tool Assistant, Chats and Flows — each overridable per project. A local-only profile no longer inherits another profile's cloud choice.
- No role ships pinned to a specific model. Each starts on automatic and picks from what your install can actually reach.
- Reasoning effort is its own control beside the model, listing only the levels that model offers. Chats carry their own effort, so turning one conversation up no longer turns them all up.
- A control always shows the model actually in effect, whether it got there by choice, by automatic selection, or by inheritance, with "Reset to defaults" to hand every role back.
- Each model says whose balance it draws down: Stimma Account credits, your own provider balance, or the machine hosting it.
- Flows name a concrete model in the program, so a flow written today still runs on what it was built against. Frozen flows capture their model at freeze time.

## Windows & Profiles

- One window per profile, browser-style. Switching profiles opens or focuses that profile's own window instead of swapping in place. The open set is remembered across restarts, and window titles carry the profile name.
- Switching profiles lands on where you left that profile, not on the previous profile's page.
- The lock screen profile picker matches the top bar.

## Chat & Flows

- Shift+Enter inserts a newline in every chat composer.
- Chat artifacts respond like the work they are: click to open in the slideshow, right-click for the context menu, for every artifact kind.
- The composer shows the reasoning level the request will actually use.
- Flows that run an LLM call across many items now run them in parallel. Results appear as they finish instead of all at once at the end, and one item can fail and retry without taking the rest with it.
- The tool assistant can generate a one-off count without changing your batch size.

## Look & Feel

- New app icon across the app and the web favicon.
- On macOS 26 Tahoe the app ships a Liquid Glass icon, so it no longer draws a ring inside the system tile.
- Voice input runs on Parakeet v3, downloaded on first use, instead of asking you to pick a transcription model.
