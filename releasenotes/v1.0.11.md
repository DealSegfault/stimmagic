# Release Notes

## MiniMax H3

- Prompt enhancement now produces MiniMax H3's task-specific audiovisual prompt format across supported text, image, first- and last-frame, and reference-to-video workflows.
- Enhancements use the selected duration, audio setting, and reference media. Requested dialogue and on-screen text remain intact, while unrequested dialogue and music are not invented.
- Reference-to-video tools accept clearly numbered picture, video, and audio references, including mixed reference types, and validate that at least one usable reference is present.
- The visible reference inputs are the ones sent to the model; hidden or stale frame selections cannot override them.

## Video Review

- Videos on the Tool stage loop silently. Selecting a clip plays one complete sound audition, then returns it to the muted loop.
- The speaker control can replay or stop an audition, shows its progress, and supports adjustable audition volume. Press `M` to audition the staged clip.
- Keyboard navigation now affects only the Tool stage on screen, so moving through one tool's results cannot move cached stages in the background.
- Slideshow volume controls open downward when there is insufficient room above them.
