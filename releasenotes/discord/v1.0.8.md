## Stimma 1.0.8 is here

Stimma has been redrawn end to end. Quieter surfaces, hairline separators instead of boxes inside boxes, one consistent set of type, color and motion everywhere. Browsers, boards and the library are contact sheets now — borderless tiles on a matte with even gutters and a single selection color.

**Chat artifacts** — the agent can stage a deliverable in chat and revise it in place, so a conversation ends with one finished asset instead of twelve near-identical ones.

Also:
- ElevenLabs voice, music and SFX on Stimma Account, with a provider-neutral voice picker
- Send to Flow: hand an asset from anywhere straight into a flow
- "Recently imported" sort, instant-apply tag picker, rebuilt info panel, context menu grouped by intent
- Emptying the trash now deletes files in your Source folders too, and it's dramatically faster
- Thumbnails load nearest-to-viewport first and stop generating for tiles you scrolled past, so long scrolls don't hose the server
- Empty unnamed boards/flows/chats from a misclick get cleaned up after 12 hours (anything you touched is safe)

Plus fixes for the slideshow control bar colliding with video transport, stale filter options, and vision capability detection on some local models.
