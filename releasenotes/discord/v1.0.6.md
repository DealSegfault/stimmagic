## Stimma 1.0.6 is here

Assets are now versioned under the hood, which is the groundwork for a lot of the editing stuff we want to do next. You'll also notice the filter UI got a real cleanup — invertible facets, empty options hidden, plus new filters for imported and unused media.

Bring your own LLM keys: OpenAI, Anthropic, Google and xAI connect directly, or route through OpenRouter, Together and Fireworks. Local models still work the same.

Also in this one:
- New first-run setup wizard + a quick sidebar tour
- Redesigned Home and Project screens
- Pay-as-you-go billing for chat models and generation tools
- Tool screen: inpaint masks survive tool hops, remixes remember where they came from, better stage mode (looping video, audio, drag, context menu)
- Flows use the tool screen's input media picker now
- Window position and size are remembered between runs
- Docs got new Browse and Generation Tools sections and a dark theme

Plus a stack of smaller fixes — closing a slideshow no longer drops your active tool, and hidden tool videos stop playing offscreen.
