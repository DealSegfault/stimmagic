# H3 examples

The read-only catalogue and middle-frame WebP thumbnails are bundled from
[MiniMax-H3 Prompt Rewriter](https://github.com/pytraveler/MiniMax-H3-Prompt-Rewriter-ComfyUI/tree/main/minimax_h3_rewriter/presets),
snapshot `made_at: 2026-09-04T09:07:22Z`. Its MIT license is retained in `LICENSE`.

Prompts and generated clips: [ostris/minimax_h3_1k](https://huggingface.co/datasets/ostris/minimax_h3_1k).
Style/subject tags: [H3 Atlas](https://cohub.live/baize/video-altas/w/h3-atlas).
Each record retains the original credits. Videos stream directly from the
dataset only when previewed; neither videos nor examples become user Assets.

These are T2VA examples, usually 5.17 seconds. Selecting a style is inspiration:
adapt visual/audio characteristics to the brief, actual duration and reference
mode rather than copying the example's story, dialogue or reference inputs.
